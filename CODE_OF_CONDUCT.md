# Code of Conduct

Brambo is a welcoming open-source project. Participants are expected to be respectful, constructive, and clear, including in issues, discussions, reviews, and code.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, doxxing, and deliberately disruptive conduct. Maintainers may remove content or restrict participation when needed to keep the project safe.

Report conduct concerns privately to the maintainers listed in [SECURITY.md](SECURITY.md). Please do not disclose sensitive details in a public issue.
