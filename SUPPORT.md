# Support

Use the channel that matches the question:

| Need | Where |
| --- | --- |
| Bug with a reproducible case | GitHub issue using the bug template |
| Feature or product direction | GitHub Discussion |
| Security vulnerability | Private report described in [SECURITY.md](SECURITY.md) |
| Help understanding the SDK | Documentation and a discussion with a minimal example |

Before asking, check the README, the package guide, existing issues, and the documented platform boundaries. Include the package/version, Node version, operating system, command, and the smallest reproduction.
