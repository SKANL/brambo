# ADR-010: Freeze the ACP client

## Status

Accepted. In force for 0.5.x.

## Context

`@brambodev/adapter-acp` was built as a stdio JSON-RPC client for the Agent Client Protocol. The session world settled on `ExecutorAdapter` over vendor CLIs and APIs, and the ACP-neutral session primitives moved into the kernel. The package had no in-repo consumer.

## Decision

The package is frozen: it is a JSON-RPC client, not an `ExecutorAdapter`, has no runtime dependency on any brambo package, and gets no new features. Verified protocol defects are still fixed.

## Consequences

- Do not build a new integration on `adapter-acp`; use an `ExecutorAdapter` or `ExecutorProvider`.
- Its errors use its own `AdapterErrorCode` strings, not `BRAMBO_*` codes.
- It remains published and versioned with the other 27 packages.

## Evidence

- `packages/adapter-acp/package.json` (no `dependencies`).
- `packages/adapter-acp/src/index.ts` (`createStdioJsonRpcClient`, `AdapterAcpError`).
- `CHANGELOG.md` and the package reference page for `adapter-acp`.
