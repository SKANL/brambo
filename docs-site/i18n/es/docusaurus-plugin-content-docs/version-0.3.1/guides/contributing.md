# Contribuir

Lee la [guía de contribución](https://github.com/SKANL/brambo/blob/main/CONTRIBUTING.md) y ejecuta `pnpm check` y `pnpm docs:check`. Mantén juntos el comportamiento, sus pruebas y su documentación.

```bash
pnpm install
pnpm check
pnpm docs:check
```
