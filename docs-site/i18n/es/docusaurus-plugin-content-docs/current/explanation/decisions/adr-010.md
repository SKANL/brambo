# ADR-010: Congelar el cliente ACP

## Estado

Aceptada. Vigente en 0.5.x.

## Contexto

`@brambodev/adapter-acp` se construyó como cliente JSON-RPC sobre stdio para el Agent Client Protocol. El mundo de sesión se asentó en `ExecutorAdapter` sobre CLI y API de proveedores, y las primitivas de sesión neutrales respecto a ACP pasaron al kernel. El paquete no tenía consumidores en el repositorio.

## Decisión

El paquete queda congelado: es un cliente JSON-RPC, no un `ExecutorAdapter`, no depende en ejecución de ningún paquete de brambo y no recibe funcionalidades nuevas. Los defectos de protocolo verificados se siguen corrigiendo.

## Consecuencias

- No construya integraciones nuevas sobre `adapter-acp`; use un `ExecutorAdapter` o un `ExecutorProvider`.
- Sus errores usan sus propias cadenas `AdapterErrorCode`, no códigos `BRAMBO_*`.
- Sigue publicado y versionado junto con los otros 27 paquetes.

## Evidencia

- `packages/adapter-acp/package.json` (sin `dependencies`).
- `packages/adapter-acp/src/index.ts` (`createStdioJsonRpcClient`, `AdapterAcpError`).
- `CHANGELOG.md` y la página de referencia del paquete `adapter-acp`.
