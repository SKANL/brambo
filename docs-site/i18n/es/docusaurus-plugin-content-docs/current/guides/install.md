# Instalar panda

Los paquetes publicados soportan Node `>=20`. El desarrollo del repositorio usa Node `>=24` y pnpm `11.23.0`.

Consulta la versión canónica en inglés para los comandos y las pruebas de consumidor.



Los comandos equivalentes son:



```bash
npm install @skanl/panda-session
```




```bash
npm install --save-dev @skanl/panda-contracts
```
