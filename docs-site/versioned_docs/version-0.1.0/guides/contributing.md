# Contributing

Read the repository [contribution guide](https://github.com/SKANL/panda/blob/main/CONTRIBUTING.md), then run:

```bash
pnpm install
pnpm check
pnpm docs:check
```

Keep behavior, tests, and its explanation together. Add a Changeset for user-visible package changes.
